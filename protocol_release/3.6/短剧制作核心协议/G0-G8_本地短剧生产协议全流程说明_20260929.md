# 本地短剧生产协议全流程说明｜G0 接入 + G1–G6｜2026-10-10

> 本文文件名保留历史名称。当前有效流程为 G0 接入与恢复 + G1–G6 六个生产 Gate；新 RUN 的显示步骤为 G0-S01 至 G6-S12。权威文件在 D 盘协议目录；Obsidian 为查阅副本。

## 适用路由

| 情形 | 执行方式 |
|---|---|
| 单条视频目标时长 ≤5 秒 | 默认对话推理，不建 RUN；用户明确要求协议留痕时例外。任何实际付费提交仍需明确授权。 |
| 进入本地协议 | G0 接入与恢复后，按任务目标执行 G1–G6；目标模式连续推进，实质剧情或授权冲突才暂停。 |
| 仅需 Prompt | 按适用流程到 G5-S09 完成生成前 QA 后结束，不进入 G6。 |
| 需生成视频 | 通过 G5 并获得本次提交授权后进入 G6；任务终态及输出链接已核实并报告后结束 RUN。 |

## Gate 定义

| Gate | 名称与职责 | 完成判据 |
|---|---|---|
| G0 | 项目接入、权威资料定位、RUN 创建或恢复 | 项目、集段、当前有效版本、请求目标与历史 RUN 已核实；不单独等待审批 |
| G1 | 权威脚本、已确认边界与节拍整理 | 权威来源、内容边界、对白/声音及节拍清楚 |
| G2 | 镜头、生产单元、调度与连续性 | 镜头因果、空间方向、道具状态和生产单元可执行 |
| G3 | 资产映射、身份锁定与最小路线 | 当前单元使用的资产、职责、路径、哈希与适用 QA 明确；只复核变化资产 |
| G4 | 可选故事本/关键状态图 | 仅有当前单元明确授权时制作；否则 `not_applicable` 且不阻塞 |
| G5 | 匹配模型 Skill、Prompt 编译与生成前 QA | 完成模型对应 Prompt Skill；Prompt、参数、成本、资产和授权一致；一次合并独立 QA 通过 |
| G6 | 单平台适配、授权提交、任务查询及结果报告 | 明确授权后最多按合同提交；原 Task ID 到真实供应商终态；记录输出链接并报告后结束 RUN |

G6 成功终态不代表视频内容通过 QA，也不代表用户认可。该 RUN 不自动下载、检查文件或分析成片。用户后续要求下载或分析时，另行建立独立任务。

## 生命周期与防循环

- 同一稳定输入哈希与审查范围只做一次完整 QA；一次轻微修正后，只对原 `issue_id` 定向复核一次。
- 产物、脚本、镜头、资产、模型参数或适用协议发生变化时，根据依赖关系只使受影响结果失效；文件名或版本标签变化本身不重置审查次数。
- 仍失败或不确定时汇总证据，提出一个具体用户决定；等待期间不重审、不重建 RUN、不执行依赖步骤。
- 恢复和协议升级沿用原 RUN、预算、提交次数、授权边界与问题历史。历史轨迹追加迁移事件，不回写旧证据。
- 文件/哈希、合同字段、资产绑定、授权、成本、平台返回状态和重复提交由确定性校验；独立模型只给内容判断。执行事实与 QA 结论是不同事件类型。
- 供应商排队/处理中是外部等待；只有 Agent 主动步骤无新事件且状态索引也无更新时才标记疑似停滞。

## 不计入 12 步的记录

- C31、C51–C68 是 Gate 内检查、返工或异常标记，不增加生产步骤。
- M01、M02 是协议读取与 attestation 记录，不增加生产步骤。
- 用户后续要求的下载、转码、剪辑或成片分析为独立任务，不回添到本 RUN。

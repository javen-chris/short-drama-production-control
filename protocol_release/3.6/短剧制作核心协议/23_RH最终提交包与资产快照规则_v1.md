# RH最终提交包与资产快照规则

用户确认：2026-10-10。QA固定 gpt-5.6-terra。

## 提交包
1. 编译完成后保存 final_submission_packet.json：最终提示词、时长、画幅、分辨率参数、上传后图片节点及文件名、参考图快照及哈希、所有关闭的外部音频输入、原接口的 workflowId 或 webappId 及 instanceType。ai-app/run 使用真实 webappId；校验不往 payload 添加不存在的 workflowId，不转换接口字段。不得包含API密钥。
2. QA只接收此包及包内快照，不得审核RH原始模板或live_nodes默认值。QA报告 final_packet_QA.json 必须包含 overall、qa_model、reviewed_packet_sha256、checks。
3. 提交前重新计算包与快照哈希。只有gpt-5.6-terra独立PASS且reviewed_packet_sha256一致才允许提交。旧QA缺此字段自动失效。提交时不重新获取模板、不重新拼提示词、不重新上传或替换资产，直接发送包内payload。
4. 编译可读取模板和上传参考文件，但不提交视频。上传返回的文件标识也纳入包哈希。引用过期需要新版本编译和审核，不能在提交过程中偷偷替换。
5. QA路由由调用程序固定。启动记录、会话ID、完成状态作为调用证据；报告明确其属于客户端执行记录，不冒充服务端认证。内容审核不得自行增加未实现的密码学身份认证门槛；调用证据缺失归为执行异常。

## 资产自动恢复
- 用户确认时记录内容SHA256、资产用途、源路径，保存任务内内容寻址快照。本次上传优先使用快照。
- 原文件改名、移动、删除或原路径内容改变：只要快照完好即可继续，保留源文件变化记录，不要求重选。
- 快照缺失：只在任务参考目录和该项目明确资产目录搜索完全相同哈希；找到后复制并复算哈希。多个副本按固定路径顺序选可读副本，无须用户裁定。
- 搜索范围受限，不扫描全盘，不跟随软链接。复制前后核验，源文件复制中变化立即停止该资产恢复。
- 同哈希即同内容。相似度、名称、分辨率不能证明同一身份。找不到完全相同内容时列相似候选供用户选择；选择后新版本绑定和审核。
- 快照本身哈希不符不得覆盖修补，暂停并保存证据。旧快照、旧包、旧审核、付费次数永不重置。

## 协议按影响范围迁移（已接线）
- 维护工具 generate 同时保存 `.protocol_versions/<fingerprint>.json` 与内容寻址的 objects 文本版本。旧清单存在但旧文本已被修改时，只保存旧哈希，不伪造历史文本。
- 新 RUN 只检查基础安全规则、执行注册表及本合同适用 protocol_refs；既有 RUN 执行前只检查基础安全规则和当前 Gate 的适用引用。无关文档变化不阻断本任务。
- `tools/migrate_run_protocol.py <项目目录> --run <RUN-ID> --inspect` 输出旧/新哈希、文本 diff、当前/后续/无关范围。历史文本缺失明确标注 UNKNOWN，不声称有完整 diff。
- 影响本合同的变化必须逐项给出 `--confirmed-path <相对路径>` 和 `--confirmation-evidence <项目内已确认记录>` 后迁移。仅无关变化可登记；身份、付费授权、QA 路由属于共同规则，仍需核对。当前证明涉及变化时标记 STALE，重新读取当前范围；事件、旧 QA、预算、Task ID、已消费提交次数保留。
- 原 RUN 不重建，不无条件刷新全部哈希掩盖规则变化。当前阶段之外的改变在后续阶段进入时检查；没有可恢复旧哈希的历史 RUN 需明确迁移。

## 控制台可用入口
- `tools/final_packet.py bind --project-root <项目> --run <RUN-ID> --packet <最终包路径>`：在生成前独立 QA 前绑定已上传图片的最终请求。S10 的编译/绑定准备提前完成，S10 正式记录只校验同包，不重新拉模板。
- `tools/final_packet.py qa --packet <最终包绝对路径> --output-directory <新QA目录>`：调用固定 Terra，只读审核包与快照，保留启动、会话、完成和原始客户端事件。
- `tools/qa_verdict.py` 在 RunningHub 的 S09 需要 `--qa-invocation-evidence <调用记录>`，报告必须对应该包的 reviewed_packet_sha256。调用证据属于客户端记录，不构成密码学身份认证，也不作为内容 FAIL。
- 平台实现调用 `production_control.final_submission.submit_bound_packet(project, run_id, send)`：send 接收包内原 payload；一次提交意图在网络前落盘，超时或返回不明保留消费次数并暂停，不自动重试。该接口不下载视频。\n

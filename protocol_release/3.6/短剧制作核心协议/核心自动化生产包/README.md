# 短剧自动化生产核心包

> 协议版本：3.0 ｜ 最后更新：2026-09-20

这是给模型首次接入短剧自动化生产时读取的精简入口，不替代原协议文件。

## 推荐读取顺序

0. `../00_自动化生产唯一入口_v3.0.md`
1. `01_核心总则_v3.0.md`
2. `02_任务路由与Gate_v3.0.md`
3. 根据任务读取 `03_生产与资产规则_v3.0.md`
4. 进入故事本、QA 或自动模式时，再读取 `04_专项规则_v3.0.md`

本包约束自动化生产的边界、状态、资产职责、连续性、QA 和授权。项目具体剧情、人物 MASTER、当前脚本、项目状态和真实尾帧仍必须从对应项目目录读取，不能由本包代替。

## 不应默认加载的内容

`templates/`、`context/`、`tools/` 和历史交接只在当前任务需要时读取。它们是执行资源，不是每次启动都要注入的核心规则。

# 故事本、QA 与文件治理

> 协议版本：3.0 ｜ 最后更新：2026-09-20

## 故事本

故事本只锁镜头顺序、人物/空间调度和动作因果；一份故事本对应一个生产单元。每格一动作，格间有因果，明确阅读顺序、时间区间、人物左右、道具位置和结束状态。正式生产优先单格生成、单格 QA、固定通过格，再本地拼版；拼版不能直接当视频画面。

故事本允许单格生成和单格 QA；但提交给视频模型时，必须上传已按格序无损拼接完成的故事本总图，禁止逐张上传同一故事本的单格图作为视频参考。单格图只用于生产、QA、修正和归档。人物、场景、道具和真实尾帧仍按各自职责单独上传。

故事本逐格检查：人物身份/人数、服装状态、空间锚点、道具数量与归属、镜头差异、因果连续、伪文字/UI、画质和特效路径。

## 视频 QA

完整播放一次，抽查开头、中段、结尾及动作/台词关键帧。由不同于生成模型的工具独立检查，每项只记 `PASS / FAIL / UNCERTAIN`，记录时码、证据、问题和最小修复建议。FAIL/UNCERTAIN 不得进入下游；通过版冻结，失败版留在 `iterations/`。

## 文件治理

整理前先审计清单、大小、哈希候选和文本引用；移动必须有 manifest 与 rollback；删除只在用户明确授权范围内执行并回查目标不存在。每次任务结束落盘任务 ID、Gate、权威文件路径、用户通过/否决、QA 证据、移动/删除记录和唯一下一步。

## 最低交付包

脚本/镜头任务：秒表脚本、镜头确认单、节拍与钩子检查、生产单元依赖图。

故事本任务：故事本任务单、资产映射表、独立 QA 报告、拼版与单格图。

视频任务：Prompt、模型参数、输入清单、任务 ID、输出路径、独立视频 QA。\n

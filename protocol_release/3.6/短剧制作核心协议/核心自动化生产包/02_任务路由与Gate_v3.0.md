# 任务路由与 Gate

> 协议版本：3.5 ｜ 最后更新：2026-10-10

## Gate 顺序

本地生产主流程为 G0 接入与恢复 + G1–G6。G0 不增加审批门禁。G6-S12 查询供应商任务至终态、记录输出链接并报告后结束 RUN；不自动下载或进行成片 QA。用户要求下载或成片分析时，另按独立任务处理。

**路由豁免优先于下表**：本次单条视频目标时长 ≤5 秒时，默认对话推理完成，不进入 G1–G6 或建立 RUN；仅用户明确要求按本地生产协议执行时才启用下列流程。此豁免不构成付费提交授权。

| Gate | 主要产物 | 进入下一 Gate 的条件 |
| G0 项目接入与 RUN 恢复 | 项目、集段、权威输入与现有 RUN 定位 | 已核实当前状态；不增加审批门禁 |
|---|---|---|
| G1 权威脚本与节拍 | 已确认脚本、边界、节拍整理 | 权威输入可定位；脚本范围明确 |
| G2 镜头与生产单元 | 镜头表、连续性、生产单元和一次独立复核 | 常规模式由用户确认；目标模式且脚本已确认可与 G1 合并交付，除非涉及剧情/台词/身份/范围变更 |
| G3 资产 | 角色/场景/道具映射 | 角色/场景/道具 MASTER 齐全；**全自动目标模式下缺 MASTER 时立即生成候选 + 独立 QA**（见 16 号授权模型）；首尾帧与故事本不阻断（按授权开关，见 03 规则） |
| G4 可选关键状态参考 | 仅用户要求/授权时制作关键状态图；未授权时跳过，不构成门禁 | 用户明确授权，且获授权产物 QA PASS |
| G5 Prompt、模型 Skill 与生成前 QA | 完整模型 Prompt、对应 Prompt Skill 证据、版本、参数、成本、输入清单和一次独立生成前 QA | 对应模型 Skill 实际运行并通过；内容/参数一致；QA PASS 并符合本单元授权 |
| G6 提交与生成 | **提交前校验、平台适配、资产绑定回读和预算核验**、平台/算力/上下文检查、资产绑定回读、可追踪任务 | 用户明确提交/生成 **且** 授权范围覆盖提交（非 `qa_only`） |
| G6-S12 任务查询与报告 | 按原任务 ID 查询终态，记录状态和供应商输出链接并报告 | 供应商终态及链接已核实；RUN 结束。下载与成片分析另建任务 |

## 风险与 QA 深度

- **L0 低风险**：简单表演或动作，使用 Shot Brief 与直接 Prompt，并执行必要的生成前 QA；成片内容 QA 按用户要求执行。
- **L1 中风险**：需要额外核对构图、站位、动作状态或道具关系；细化镜头/动作拆解并增加生成前 QA 项。
- **L2 高风险**：多人走位、接触/打斗/交接、复杂道具、跨空间或反转；加强动作因果拆分、Prompt 禁止项和生成前 QA。用户提出时再做成片 QA。

L0/L1/L2 只决定风险记录与 QA 深度，不授权生成图片。故事本图片、关键状态图和拼版默认关闭；只有用户明确要求或授权当前生产单元制作时才启用 G4/S07。未授权时不创建故事本任务单或 QA，不得因缺故事本阻断后续 Gate。首尾帧按各自授权规则处理。**角色/场景/道具 MASTER 是身份权威，不可用相似图替代**：目标模式缺 MASTER 的处理按 16 号规则；QA 未 PASS 的候选不得进入下游。

镜头数量不等于视频提交数量；故事本张数也不等于生产单元数量。以模型稳定性、连续性和动作风险决定拆分。

## 目标模式

用户明确"全自动/目标模式 + 项目 + 集/段 + 产物/时长"时，自动建卡、合同草案、资产映射、生产单元和状态记录；不得自动创建故事本任务单。缺故事本不是暂停条件：合同记录 `storyboard_mode=disabled_by_default`，故事本步骤为 `not_applicable`，继续到 G5/G6。只有用户明确授权当前生产单元时才创建故事本任务单。其他暂停与 MASTER 处理规则按对应权威文件执行。\n

# QA 与文件治理

> 协议版本：3.4 ｜ 最后更新：2026-10-01

## QA

生产前 QA 的 A/B/C 是互斥审查范围，不是逐级流程：对稳定候选只选择一个最小充分等级；C 级将当前候选所需脚本、镜头、Prompt、资产合同与项目状态合并审一次，并分别记录各项结论。同一候选不重复跑 A、B、C。材料发生实质变化时，以新版本重新选级。成片 QA 仅在用户明确要求模型/Agent 分析时执行；不属于当前 G0-S01 至 G6-S12 生产流程。

G4/S07 仅在当前生产单元获故事本授权后适用；未授权时不创建任务单、不执行本节故事本 QA。权限与默认路线以 `核心自动化生产包/03_生产与资产规则_v3.0.md` 为准。以下 QA 清单仅适用于实际纳入当前单元的已授权故事本。


### 独立 QA 模型路由

生成前 QA 和用户要求的成片 QA，都必须由与执行模型不同、且按明确路由指定的 GPT 模型完成。执行模型不得自审；不得自行换审核模型。2026-10-10 用户明确指定 GPT-6.1 Sol 使用 GPT-5.6 Terra 独立 QA，不使用 Astra；这条指定优先于能力档位规则。QA 模型需同时满足本节路由表、控制台 `capabilities/qa_policy.json` 的 Gate 白名单，并由 QA 模型本人写入轨迹结论。

当前可用 GPT-6 型号与生成前 QA 路由：

| 执行模型 | 独立 QA 模型 | 处理 |
|---|---|---|
| `gpt-6-luna` | `gpt-6-sol` | 按高一级工作模型审核 |
| `gpt-6-sol` | `gpt-6.1-sol` | 由更新一代的工作模型审核 |
| `gpt-6.1-sol` | `gpt-5.6-terra` | 用户指定独立审核；禁止对此路由使用 Astra |
| `gpt-6-astra` | 无 | 阻断；没有更高的独立审核档位，不得自审或降级 |

模型 ID 必须与当前可选模型目录一致。当前目录没有 `gpt-6-terra`，所以 GPT-6 Luna 的审核模型设为可用的 `gpt-6-sol`；不得把不存在的型号写进路由或假装已调用。若后续模型目录新增 Terra 或更高档型号，再更新配置、文档和测试后启用。

GPT-5.6 的已有路线作为兼容规则保留：`gpt-5.6-luna → gpt-5.6-terra`、`gpt-5.6-terra → gpt-5.6-sol`、`gpt-5.6-sol → gpt-5.6-luna`。这些映射保持已有 RUN 可审计；历史轨迹只读，不得重写。对未登记的执行模型或没有更高审核模型的最高档模型，一律 fail-closed 阻断，不回退到同级/较低模型、GLM、人工猜测或生产者本人。

每次 QA 记录调用方固定的模型路由、启动记录、会话 ID、完成状态、版本、QA 等级、耗时、受影响文件及证据。上述证据如实标注为客户端执行记录，不冒充服务端认证。内容 QA 不得自行增加工具未实现的密码学身份认证门槛；缺失调用记录属于执行异常，与内容 FAIL 分开。RunningHub 只审核已编译且上传绑定完成的最终包及快照，固定 gpt-5.6-terra，记录 reviewed_packet_sha256；提交同包。QA PASS 不代替用户的生成/付费授权。
### 故事本 QA（G4）

逐格核对：

- 人数与身份：每人是否对应指定 MASTER；无克隆、无多余人/肢体。
- 服装与状态：发型、服装、伤势、鞋子与前段一致。
- 空间：场景锚点、门/窗/桌/装置位置、镜头屏幕方向连续。
- 道具：数量、归属、位置、大小、是否在正确手中。
- 镜头：每格景别和机位有区别；没有伪文字、拼格线或无关 UI。
- 因果：当前格能接前一格并为下一格提供可执行状态。

### 成片内容 QA（独立用户请求）

成片画面/声音分析不是视频生成后的默认步骤。新 RUN 在 G6-S12 查询供应商任务至终态、记录输出链接并报告后结束；不自动下载或启动成片 QA。只有用户明确要求分析视频时，才另建独立任务并执行以下 QA：

- 完整播放一次；抽取开头、中段、结尾及动作/台词关键帧。
- 使用不同于生成模型的独立 QA；每项只写 `PASS / FAIL / UNCERTAIN`。
- 逐条记录：时码、证据文件、问题、最小修复建议。
- 用户判定优先。通过版冻结；失败版留 `iterations/`，不替换或覆盖通过版。

## 整理、移动与删除

1. 先审计：文件清单、大小、哈希候选、文本路径引用。
2. 再移动：必须有 CSV manifest、理由、目标路径和 rollback 脚本；不覆盖同名 MASTER。
3. 最后删除：只对用户明确授权的范围执行，记录逐件删除 manifest，完成后回查目标路径不存在。
4. QA 联系表、抽帧图、时码概览放 `qa/` 或共享库的 `参考图与生产过程参考/`；不是人物/场景/物品 MASTER。
5. 封面、标题版、发布图只放 `封面与发布物料/`。

## 每次任务结束时必须落盘

- 当前任务 ID 和 Gate；
- 权威脚本/故事本/Prompt/视频路径；
- 用户明确通过或否决的内容；
- QA 结果与证据；
- 发生的移动/删除 manifest；
- 下一步和唯一待用户决定事项。\n

# 标准项目目录与文件职责

> 协议版本：3.0 ｜ 最后更新：2026-09-20

每个新短剧项目或新集必须单独建根目录；不要在旧集目录里直接开新集。人物 MASTER 留系列总库，本集仅引用，不搬迁为唯一源。

```text
<项目根>/
├─ 00_项目入口.md
├─ workflow/
│  ├─ project_state.json
│  ├─ image_channel_log.json        # 生图元数据台账（一个项目一份，只记路径引用，不复制图片）
│  ├─ FINAL_HANDOFF_YYYYMMDD.md
│  ├─ 确认单/
│  └─ qa_reports/
├─ 脚本/
├─ design/
├─ 场景资产/
├─ 物品资产/
├─ 故事本&首尾帧/
├─ 提示词/
├─ 视频/
├─ qa/
├─ recordings/incoming_user/
├─ iterations/
└─ _archive/
```

**资产存放原则（避免重复占空间）**：

- **图像本体只存一份**，就放在上表的资产目录（或系列库 `人物资产库/` 等）里。同一张图**不得**为了"留档"在其他位置再存一份。
- `workflow/image_channel_log.json` 是**元数据台账**：记录每张图的生成通道、模型、成本、证据与**相对路径引用**，不内嵌图片、不复制文件。**一个项目一份**，追加式，不要每张图建一个文件。
- 上述台账不复制图片。经确认用于某个 RUN 的输入可以按 `24_资产索引与RUN恢复规则_v1.md` 保存为该 RUN 的不可变快照；快照仅是来源证据，不是新 MASTER，也不得覆盖权威资产。
- **路径不写死**：若项目在 `00_项目入口.md` 里声明了自己的资产目录或台账位置，**以项目声明为准**；规则只要求"图片能被引用到、台账能被读懂"。

## 根级共享库建议

```text
<系列根>/
├─ 人物资产库/<角色>/             # 用户确认的角色 MASTER
├─ 场景资产库/                      # 可跨集复用场景 MASTER
├─ 物品资产库/                      # 可跨集复用道具 MASTER
├─ 参考图与生产过程参考/             # 真实尾帧、镜头参考、过程参考
├─ 封面与发布物料/                   # 所有封面、标题版、发布包
└─ <每集独立生产目录>/
```

## 命名

- 任务：`<项目>-<EP>-<段>-<阶段>-V<n>`
- 脚本：`EPxx_<段>_<内容>_脚本_v<n>_<状态>.md`
- 故事本：`EPxx_<段>_<秒数>_故事本_v<n>.png`
- Prompt：`EPxx_<段>_<模型>_视频提示词_v<n>.md`
- 视频：`EPxx_<段>_<模型>_<秒数>_v<n>.mp4`
- QA：`EPxx_<段>_视频QA_v<n>.md`

状态只能是：`DRAFT`、`WAITING_USER_CONFIRM`、`APPROVED`、`REJECTED`、`SUPERSEDED`、`ARCHIVED`。不要用“最终版”当状态；必须有版本号和用户确认记录。\n

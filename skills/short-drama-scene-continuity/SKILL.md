# Scene continuity

Read the current project's scene, character, costume, prop MASTER indexes and `D:\短剧制作核心协议\03_资产与连续性规则.md`. Never invent a missing state or use a concept image, contact sheet, or storyboard as a real tail frame.

For each production unit output a continuity ledger containing: scene ID and MASTER; time/weather/light direction; fixed spatial anchors; character position, facing, eyeline, entrance/exit and screen direction; wardrobe/body/condition state; prop count, owner, hand and state; established 180-degree axis; input state; output state; transition type; and real-tail-frame dependency.

Compare each output state with the next input state field by field. A mismatch must be resolved by an approved story change, explicit on-screen change, establishing move, or hard cut. Otherwise return `FAIL` or `UNCERTAIN` and block asset routing.

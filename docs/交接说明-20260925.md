## 一、这套系统是什么

一句话：**把"短剧生产流程有没有按协议走"变成看得见、可审计的东西。**

它本身**不生产任何内容**。它做三件事：

1. **记录** —— 生产 Agent 每完成一步，就往轨迹里写一条事件（谁做的、读了哪份协议、证据在哪）。
2. **审计** —— 拿轨迹和协议声明的步骤逐条对账，找出「声称做了但没证据」「做了但没读协议」「根本没做」。
3. **展示** —— 一个本地网页看板，让人一眼看出跑到哪、卡在哪、等谁拍板。

生产规则本身**不在这个仓库里**，在仓库外的协议目录（见第三节）。

```
生产 Agent（灵枢 / Codex 等）
   │  ① python tools/append_event.py  → 写「我提交了这一步」
```

## 七、写权限模型（这套系统的核心设计）

**"生产者不能给自己的活签字。"** 这不是文档里的要求，是代码强制的：

| 谁 | 能写什么 | 拒绝什么 |
|---|---|---|
| 生产模型（`role=producer`） | `SUBMITTED_FOR_QA` / `BLOCKED` / `WAITING_APPROVAL` / `PAUSED_EXCEPTION` | 写 `COMPLETED` → `WRITE_AUTHORITY_VIOLATION` |
| QA 模型（`role=qa`） | `COMPLETED`（=通过）/ `FAILED` | actor 与生产者相同 → `SELF_QA_VIOLATION`；给没人提交过的步骤出结论 → `QA_WITHOUT_SUBMISSION` |

其他写入端强制项：
- `--evidence` 指向的文件**必须真实存在**，否则拒绝（`FileNotFoundError`）
- 完全不给 `--evidence` → `MissingEvidenceError`（曾经只是警告，等于可以绕过）
- `--step` 无法解析 → `UnknownStepError`，**回显全部合法名字**
- 协议链外的动作必须显式 `--off-protocol`，否则拒绝

**第 6 轮 · 修「索引过期」假告警（写交接文档时顺带发现）**
看板上那个红色「索引可能过期」是**假警报**。索引的时间戳由 `run_index._now()` 写成 **UTC**
（`12:17:39+00:00`），事件由 Agent 写成**本地时间**（`20:17:39+08:00`），两者是**同一瞬间**，

另加 3 条回归测试（同一瞬间不算旧 / 真旧要报 / 解析不了不报警）。

## 十一、本机环境陷阱（都是踩过的）

| 坑 | 事实 |
|---|---|
| **PowerShell 工具 stdout 不回传** | 命令成功（exit 0）但看不到输出 → 诊断脚本必须**写文件再用 Read 读** |
| **Bash `curl` 访问 localhost 要加 `--noproxy '*'`** | 环境变量 `HTTP_PROXY` 指向沙箱代理且 `NO_PROXY` 为空 → 不加会返回 502，**极易误判成"服务挂了"**（浏览器不受影响，系统代理绕过 `127.*`） |
| **沙箱留不住常驻服务** | 从 agent 会话起的进程会随会话被回收。`nohup`/后台任务/`Start-Process` 全失败，`schtasks` 被安全策略禁用 → **看板必须由用户双击启动** |
| **不要在 present_files 里给 localhost URL** | 除非该进程由用户侧启动，否则用户点开就是"打不开" |
| **`.cmd` 必须纯 ASCII** | cmd.exe 按 OEM 代码页（936/GBK）读批处理，UTF-8 中文会撕裂后续行解析。中文输出一律放 Python |
| **删除会进回收站** | `Remove-Item` / .NET `Directory.Delete` / COM `InvokeVerb` 全被 safe-delete 垫片重定向到回收站，"删除成功" ≠ "空间释放" |
| **safe-delete 会「报错但已删」** | 报 trash-failed 但文件其实没了 → **删完必须复查真实状态** |
| **`wmic.exe` 已被 Win11 移除** | 用 `(Get-CimInstance Win32_Process -Filter "ProcessId=N").CommandLine` |
| **`Get-ChildItem Env:` 报错** | 本机有重复环境变量键 → 改用注册表或 `[Environment]::GetEnvironmentVariable()` |
| **截图看 UI 不用装工具** | 本机已有 Chrome：`chrome.exe --headless=new --screenshot=out.png --window-size=1280,1100 --blink-settings=preferredColorScheme=1 <url>`，然后**用 Read 看图** |
| **起服务+截图必须在同一条 bash 命令里** | 否则服务随上一条命令结束被回收 |

## 十三、改代码的规矩（读一遍再动手）

1. **改步骤定义只改 `skills/skill-chain.json` 一处。** 别在 Python 里再抄一份 —— 有守卫测试会红。
2. **改 UI 先截图看。** 用第十一节的 Chrome 命令；凭想象做设计正是之前界面失控的原因。
3. **写守卫测试要验证它会红。** 注入坏值 → 确认 FAIL → 移除 → 确认 PASS。
4. **不要让展示层静默丢弃它无法归类的东西。** 归不了类本身就是最重要的信息
   —— 第 2 轮的 bug 就是一行 `continue` 丢掉了全部答案。
5. **拒绝时要说清怎么办。** 错误信息要带**合法清单 + 最近候选 + 一条可复制的命令**，
   不只是"输入无效"。
6. **注释解释"为什么"，不解释"是什么"。** 现有代码风格如此，请保持。

# 已退役的启动器（2026-09-25 合并）

这两个脚本原先放在仓库外的 `D://AIGC短剧本地工作流规则及协议//` 下，
都会调用 `tools\start_run_board.py` 的交互式菜单来选项目。

现在启动入口已合并为仓库内的**唯一一个**：

    D://AIGC短剧本地工作流规则及协议//短剧生产线控制台//tools//一键打开看板.cmd

切换项目改为编辑 `tools\board-project.txt`（一行路径）。
桌面上的「短剧看板」快捷方式指向同一个入口，所以"不想进 tools 目录"的需求并未丢失。

**为什么合并**：5 个入口 × 3 条代码路径 × 2 套项目选择机制，
彼此行为不一致；双击两个不同的入口还可能互相杀掉对方的看板
（旧启动器会回收端口，而它的渲染进程刚被杀掉又会触发它自己的重启）。

文件内容原样保留在此，仅作留痕。若需恢复，复制回仓库根目录的上一级即可。

# 决策记录：Prompt 优先与自适应资产路由

状态：已确认，纳入生产线设计基线

## 已确认方向

1. 视频生产默认使用 Prompt-first，不默认制作完整故事本。
2. 所有视频 Prompt 必须由仓库中的 Prompt Skill 生成，并经过独立 QA `PASS`。
3. 故事本只在 Prompt 无法稳定约束复杂画面时触发。
4. 视频生产渠道固定为 RunningHub、小云雀、LibTV；三者共用同一份合同、资产职责和 QA 状态。
5. 资产不要求全部在前期一次性生产。系统应按当前镜头的真实风险识别缺口，只建议并补齐最小必要资产。

## 自适应路由

```text
脚本确认 → 节拍/镜头拆解 → 资产缺口与风险扫描
  ├─ Prompt 能稳定约束 → PROMPT_ONLY_READY
  ├─ 只缺关键状态 → KEYFRAME_REQUIRED
  ├─ 缺角色/场景/道具权威图 → ASSET_PLAN_REQUIRED
  └─ 多人调度/接触/跨空间/复杂特效 → STORYBOARD_REQUIRED
```

## 模型必须给出的判断记录

每个生产单元必须记录：风险因素、缺失资产、最小补齐方案、推荐路线、理由、额外成本/工作量、阻断条件。模型可以自动完成分析和非付费草案，但不得猜测缺失 MASTER。

## 权限边界

资产计划、Prompt 草案和 QA 清单可以自动生成；生成新资产、调用视频渠道、重试、换模型、增加预算、发布或覆盖 MASTER，仍必须由 `production_contract.json` 明确授权。

## 持久化要求

沟通结论只有写入本仓库的决策记录、Schema、Skill、测试或任务状态后，才算生产线规则。聊天窗口关闭不影响已提交内容。

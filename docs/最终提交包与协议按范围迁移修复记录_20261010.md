## 同日补充：QA 包哈希口径

final_packet_qa.py 的调用提示词明确使用整个 parsed JSON 对象的规范哈希：`hashlib.sha256(json.dumps(packet, ensure_ascii=False, sort_keys=True, separators=(',', ':'), allow_nan=False).encode('utf-8')).hexdigest()`。原 JSON 文件字节哈希、缩进、空格、换行和对象键顺序不用于 reviewed_packet_sha256；图片 sha256 仍基于文件原始字节。新增排版不影响审核及真实内容变化仍使 QA 失效的回归测试，最终包集成定向验证 15 passed。digest_packet 实现保持不变，未改生产包、未提交视频。此补充只修改调用提示词/测试/修复记录，权威协议 manifest 覆盖文件未改变。
